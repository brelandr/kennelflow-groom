# KennelFlow Groom 0.2.6

Since WordPress.org **0.2.1**.

## Staff calendar & groomer access

- Groomers: `groompress_view_calendar`, `groompress_create_bookings`, and `groompress_edit_hub_pets` for the shared Hub staff calendar and pet records.
- Grooming schedule defaults on the staff calendar; Add booking modal defaults to **Grooming**.
- Hub dashboard trimmed for groomers; vet Rooms/Locations hidden where appropriate.
- Fix: Hub calendar capability no longer forces groom calendar cap on every role (vet/boarding staff regained correct views).

## Session photos (with KennelFlow Groom Pro)

- Calendar settings for before/after session photos passed to all calendar viewers.
- Groomers receive `upload_files` when Groom Pro is active.
